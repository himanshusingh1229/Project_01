Java Object-Oriented Programming

Object-oriented programming (OOP) is a way to organize a program around objects. An object combines information (its data) with actions it can perform (its methods).

Classes and objects

A class is a reusable plan. An object is one thing created from that plan. For example, a Car class could describe a car's color and provide a drive() action. A red car and a blue car would be separate objects made from the same class.

Four common OOP ideas

Encapsulation keeps an object's data and related methods together. Inheritance lets a class reuse features from another class. Polymorphism lets different objects respond to the same action in their own way. Abstraction shows the important controls while hiding implementation details.

Small example

A Dog object might store its name and have a bark() method. The class describes what dogs can do; each dog object can have its own name.
